отечественном хостинге (Helios ИТМО).

## Краткие итоги

- **T1:** для научного контента оптимален Sphinx + MyST (87 из 100), Quarto рядом (83).
  MkDocs Material выигрывает только для документации без формул. Подробнее — в [T1](t1.md#когда-вывод-меняется).
- **P2:** Sphinx реализовал всю страницу встроенными средствами. MkDocs потребовал ручного HTML для
  таблицы и дал смешанный список литературы. Pelican потребовал своего плагина, шаблона и ручной
  нумерации.
- **Развёртывание:** одна сборка на каждую площадку, строгий режим всех трёх генераторов, проверка
  после деплоя с имитацией недоступных CDN.
