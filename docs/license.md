# Лицензии

Код и контент лицензированы раздельно: у них разная природа и разные риски при повторном использовании.

| Что | Лицензия | Файл |
|---|---|---|
| Исходный код: `scripts/`, `p2/**/*.py`, плагин `bibcite`, шаблоны, конфигурации, workflow | MIT | [`LICENSE`](https://opensource.org/license/mit) |
| Тексты отчёта, таблицы, рисунки, синтетические данные | CC BY 4.0 | [`LICENSE-CONTENT.md`](https://creativecommons.org/licenses/by/4.0/deed.ru) |
| MathJax 3.2.2 (`p2/shared/vendor/tex-svg.js`) | Apache 2.0 | сторонний компонент |
| plotly.js (копируется из пакета `plotly` при сборке) | MIT | сторонний компонент |

**Почему так:**

- **MIT для кода** — минимум условий, совместима с лицензиями зависимостей (MkDocs — BSD-2,
  Sphinx — BSD-2, Material — MIT).
- **CC BY 4.0 для контента** — стандарт для открытых научных материалов: разрешает переиспользование
  с указанием авторства. Код под CC лицензировать не рекомендуется: в CC нет положений о патентах
  и о распространении исходного кода.
- **Pelican под AGPL-3.0** на лицензию сайта не влияет: генератор только запускается при сборке
  и в результат не попадает. Тема `notmyidea` распространяется вместе с Pelican, а её CSS попадает
  в `_build/site/p2/pelican/theme/`. Это стоит учитывать при выборе Pelican для публичного сайта.
